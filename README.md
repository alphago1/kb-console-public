# KB Console — Word-first 本地知识库管理系统

将桌面随手记的 `.docx` / `.md` / `.txt` 自动分类、全文检索、AI 深度分析的个人知识库。

## 核心功能

### 数据接入
- 扫描桌面或任意目录的新文件（`.docx/.doc/.md/.txt`）
- 自定义文件夹选择 + 递归开关，实时预览文件数
- LibreOffice 提取 Word 文本，智能采样（前/中/后/随机段）

### AI 自动分类
- DeepSeek v4-flash 自动分类，将文件归入知识库目录（AI与工具化、交易系统与方法论等 11 个分类）
- 低置信度自动触发深度重读，标签归一化清洗
- 支持规则+LLM 混合策略，课程材料自动识别

### 全文检索（Find）
- **快速搜索**：SQLite FTS5 关键词匹配，毫秒级返回
- **智能搜索**：Agent 多轮调用知识库工具，理解自然语言问题
- 按分类/月份过滤，文件名+正文双重命中

### 自定义分析（Custom Analysis）
- **主题分析**：选文件夹+时间范围+主题，LLM 深度分析（预设交易系统/AI项目模板）
- **文件夹分析**：全文打包→Token预估→LLM 答疑（两步操作，Bundle 零费用预览）
- **个人画像**：基于全量/自定义范围的知识输入，生成认知画像报告
- 超出 100 万字自动分批 LLM 压缩+并发处理+串联合成

### 整理与维护
- 每周整理：扫描→分类→写入→生成周报，后台执行+实时进度
- 课程转写压缩：录音转写文件 LLM 压缩为结构化笔记

### 报告与设置
- 报告中心：按类型分组浏览/预览/下载历史报告
- 设置可读写：LLM配置、路径配置、扫描参数，DeepSeek 连接测试，系统健康诊断

### MCP 服务
- Model Context Protocol 标准接口，Claude Desktop / Cursor 可直接集成
- 7 个工具：文档搜索、Chunk 检索、文档获取、时段对比、月度摘要、写作候选、项目想法聚类
- 路径脱敏、审计日志、权限控制

## Novelty

1. **Word-first 设计**：直接管理 `.docx` 原始文件，不要求用户改变记笔记习惯。桌面随手建的 Word 文件自动入库
2. **确定性内容指纹**：全文 SHA256 作为文件唯一 ID，解决传统 mtime/随机采样去重的不可靠问题
3. **Budget-aware 分析**：100 万字 Token 预算制，超出自动分批→LLM 压缩→合成，不丢数据不超上下文
4. **Agentic Search**：用已有 MCP 工具链实现语义级搜索，零额外基础设施成本（不需要向量数据库）
5. **后台任务体系**：所有长操作（整理/分析/画像）线程化异步执行，切页面不丢进度，完成有 toast+提示音
6. **通用化分析引擎**：不硬编码"交易分析"，用户自选文件夹+时间+主题，预设模板一键填充

## 技术栈

| 层 | 技术 |
|----|------|
| 语言 | Python 3.13 |
| GUI | Streamlit 1.56 |
| 存储 | SQLite + FTS5 |
| LLM | DeepSeek v4-flash（可替换） |
| 协议 | MCP (Stdio + HTTP) |
