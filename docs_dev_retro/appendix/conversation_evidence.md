# 附录 A — 关键对话证据

**用途**：保存开发过程中的关键对话片段，作为复盘文档中结论的证据支撑。

**读者**：自己（写复盘时引用）/ 想深入了解交互细节的人。

**怎么填**：摘录对话中的关键转折点。每条包含：时间、对话片段、这一段说明了什么。

---

## 格式

```
### 2026-05-03 — 需求明确：交易分析应该通用化

**用户**：
"交易分析 不太好这么安排 最好将其作为个性功能的一个子栏目...
因为交易分析本质是分析某一段时间的某个主题情况"

**说明**：这次对话直接触发了"自定义分析"模块的设计。
```

---

## 待填充的关键对话

- 需求触发点：交易分析 → 自定义分析
- bug 发现：用户指出重复文件
- bug 发现：搜索无结果
- bug 发现：子进程卡住
- 设计反馈：文件夹选择器应该用浏览对话框
- 设计反馈：后台任务应该跨页面可见
- 设计反馈：分析上限应该是 100 万字而非 80 篇
- 设计反馈：分批处理应该并发
